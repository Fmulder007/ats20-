# ATS-FM — индивидуальная память КВ-бэндов

Отдельная копия ATS_EX Goshante v1.18 с доработкой памяти КВ-поддиапазонов.
Исходная папка `ATS_EX` в репозитории не изменялась.

**Вариант прошивки:** ATS-FM v1.19  
**EEPROM APP_VERSION:** 119  
**EEPROM APP_ID:** 235 (сохранён исходный идентификатор)

## Что изменено

### Индивидуальная память 19 КВ-поддиапазонов

Массив `SWSubBands[]` сохранён без изменений. Каждое его значение трактуется как нижняя граница соответствующего участка:

- нижняя граница: `SWSubBands[i]`;
- верхняя граница: `SWSubBands[i + 1] - 1`;
- для последнего участка верхняя граница — `SW_LIMIT_HIGH` (30000 кГц).

Это именно интервалы исходного алгоритма ATS_EX, а не новая таблица официальных любительских выделений частот.

Для каждого из 19 участков хранится собственная последняя частота. Добавлен также отдельный сохранённый индекс последнего выбранного КВ-поддиапазона: он позволяет вернуться к последнему участку после переключения на LW/MW/FM и после перезапуска.

### Поведение настройки и переключения

1. Внутри всего КВ-диапазона сохраняется свободная непрерывная настройка от 1710 до 30000 кГц.
2. При вращении энкодера, поиске станции и настройке SSB/BFO программа определяет участок по текущей частоте и обновляет его значение в RAM.
3. При BAND+ или BAND- частота текущего КВ-участка немедленно сохраняется в EEPROM.
4. Затем выбирается соседний КВ-участок и загружается его последняя сохранённая частота.
5. Если сохранённая частота выходит за границы своего участка, она считается недействительной. Вместо неё в RAM устанавливается исходная точка из `SWSubBands[i]`. Исправленное значение попадёт в EEPROM при следующем штатном сохранении.
6. На первом/последнем КВ-участке BAND- / BAND+ по-прежнему переводит приёмник в соседний основной диапазон.

При SSB в памяти учитывается частота с применённым BFO (`g_currentFrequency + g_currentBFO / 1000`), то есть та частота, которой соответствует настройка на шкале.

### Автоматическое сохранение

Существующий механизм Goshante сохранён:

- после 10 секунд бездействия по частоте вызывается `saveAllReceiverInformation()`;
- при закрытии меню настроек вызывается то же полное сохранение;
- при переходе BAND+ / BAND- с КВ-участка его частота сохраняется немедленно.

В полное сохранение добавлены индекс активного КВ-участка и частоты всех 19 участков. Используется исходный `EEPROM.update()`.

## EEPROM

При стандартной конфигурации `USE_RDS = 1` раскладка следующая:

| Адреса | Содержимое |
|---:|---|
| 0 | APP_ID |
| 1–8 | Общие параметры приёмника |
| 9–24 | Частота, шаг и полоса LW/MW/SW/FM |
| 25–40 | Пользовательские настройки |
| 41 | Индекс последнего выбранного КВ-поддиапазона |
| 42–79 | 19 частот КВ-поддиапазонов, по 2 байта |
| 1000 | APP_VERSION |

Новая часть занимает 39 байт: 1 байт индекса и 38 байт частот. Адрес версии 1000 не менялся.

## Миграция EEPROM с ATS_EX v1.18

При первом запуске ATS-FM:

- читаются прежние общие настройки и записи LW/MW/SW/FM;
- прежняя единственная SW-частота переносится в тот новый участок, в границы которого она попадает;
- остальные КВ-участки получают начальные частоты из `SWSubBands[]`;
- новая структура записывается с версией 119.

При загрузке версии 119 каждая из 19 частот проверяется по границам своего участка. Неверные значения заменяются начальными значениями в RAM; они не записываются немедленно только из-за факта обнаружения ошибки.

Маркер версии 119 записывается последним, после остальных данных, чтобы незавершённое сохранение можно было повторить при следующем включении.

## Состав папки

- `ATS_EX.ino` — основной скетч; имя сохранено для совместимости с исходным Visual Micro-проектом.
- `globals.h` — массив RAM для памяти поддиапазонов.
- Остальные исходные `.h` и `.cpp` — копия необходимых файлов ATS_EX.
- `ATS-FM.vcxproj`, `ATS-FM.vcxproj.filters`, `ATS-FM.sln` — отдельный Visual Studio / Visual Micro проект.
- `README.md` — это описание изменений.

## Проверка

Исходный проект ATS_EX не менялся. Эта папка содержит отдельную экспериментальную версию.

Сборка, проверка фактического размера Flash/SRAM и испытания на ATS-20+ не выполнялись. Их нужно сделать перед использованием прошивки на приёмнике. Особое внимание — доступному запасу Flash ATmega328P: исходная ATS_EX v1.18 уже близка к пределу размера программы.
